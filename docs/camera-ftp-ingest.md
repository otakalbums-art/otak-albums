# Прийом фото з Wi-Fi камер по FTP

Один FTP-логін на клас — його вистачає на будь-яку кількість камер цього
класу одночасно. Кілька камер розводяться по категоріях не окремими
логінами, а різною **цільовою папкою (Directory)** в налаштуваннях FTP
кожної камери (детальніше — крок 3). Кожне фото, скинуте камерою, одразу
зʼявляється в галереї учнів класу (без ручного завантаження) — завдяки
вже наявній real-time підписці на нові фото
(`apps/client/app/gallery/page.tsx`).

## Вимоги

- Камера з Wi-Fi-модулем і **вбудованою підтримкою FTP-вивантаження**
  (типово в напів-профі/профі тілах: Canon EOS R/1D-series з бездротовим
  передавачем, Nikon Z8/Z9/D850+, Sony a7 IV/a9+...). Камери, у яких Wi-Fi
  уміє лише "передати на телефон через фірмовий додаток" (Canon Camera
  Connect, Nikon SnapBridge тощо, без прямого FTP) — цей спосіб не
  підійде, потрібен інший шлях імпорту.
- Комп'ютер з адмінкою і камера — в **одній Wi-Fi мережі**.
- FTP тут — простий, без шифрування (стандартна практика для закритої
  локальної мережі на зйомці; більшість камер FTPS/SFTP і не підтримують).

## 1. Запусти приймач

Окремо від звичайного `pnpm dev` (в іншому терміналі, поки триває зйомка):

```bash
pnpm --filter admin run ftp:start
```

У консолі побачиш локальні IP-адреси комп'ютера і порт — ті самі дані є в
адмінці на вкладці **«Прийом з камер (Wi-Fi)»**, разом з логіном/паролем
для кожного активного класу.

## 2. Налаштуй камеру (одноразово на клас/камеру)

У меню камери (шлях залежить від моделі, зазвичай `Мережа` /
`Network` → `FTP-передача` / `FTP transfer`):

| Поле | Значення |
|---|---|
| Host / Сервер | IP комп'ютера з адмінки (з вкладки «Прийом з камер») |
| Порт | `2121` (не стандартний 21 — так простіше без адмін-прав на комп'ютері) |
| Логін | з вкладки «Прийом з камер» — **той самий для всіх камер цього класу** |
| Пароль | з вкладки «Прийом з камер» — так само спільний |
| Режим | Пасивний (Passive / PASV) |
| Цільова папка | див. крок 3 — тут відрізняються різні камери одного класу |
| Автовивантаження | Увімкнути "вивантажувати кожен кадр одразу після зйомки" |

Збережи налаштування, зроби тестовий кадр — за пару секунд він має
з'явитись у галереї учнів цього класу.

## 3. Декілька камер в один клас — різні папки

Логін/пароль однакові для всіх камер класу. Розводить їх поле
**Цільова папка (Directory / Target folder)** в налаштуваннях FTP кожної
камери — назва підпапки визначає категорію фото:

| Папка на камері (Directory) | Категорія фото |
|---|---|
| `/` (не вказувати взагалі) | Без категорії |
| `/portrait` | Портрети |
| `/group` | Групові |
| `/ceremony` | Церемонія |
| `/personal` | Персональні (без прив'язки до учня — приєднати можна пізніше вручну через адмінку) |

Підпапки вже існують заздалегідь (створюються автоматично при першому
підключенні класу) — камері не треба вміти створювати директорії, лише
зайти в уже наявну.

## Обмеження

- `personal` через FTP — без прив'язки до конкретного учня (набирати
  UUID учня в тісному меню камери нереалістично); за потреби прив'язати
  фото до учня можна пізніше вручну.
- Лише `.jpg`/`.jpeg` (перевіряється і за розширенням, і за magic bytes
  файлу) — RAW/HEIC тощо буде проігноровано.
- Немає живого статусу "сервер запущено" в UI адмінки — орієнтуйся на
  консоль, де запущено `ftp:start`.
